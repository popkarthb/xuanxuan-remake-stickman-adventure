# 萱萱小游戏：火柴人大冒险重制版

一个根据童年记忆重制的极简固定屏幕火柴人探险小游戏。

当前版本包含 9 个固定屏幕：1 个六门选区大厅、6 个彩色区域和 2 个相互连接的深层区域。

## 运行

```bash
python -m pip install -r requirements.txt
python main.py
```

## 操作

- `←` / `→` 或 `A` / `D`：移动
- `↑` / `W` / `Space`：跳跃
- `Z` / `J` / `Left Ctrl`：开枪；弹药耗尽后自动使用拳头
- `R`：重新开始
- `Esc`：退出

人物接触拱门会自动切换房间。大厅六扇门默认全部开放；区域内部存在钥匙门、开关门、单向路线和非空间逻辑连接。敌人的子弹速度较慢，但命中一次就会让整个游戏重新开始。
